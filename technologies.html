01 / Our technology stack Design · Develop · Deliver

The right tools make good products possible.

Our technology stack is built around practical tools that help us design, develop and connect modern digital products.

For frontend development we work with React.js, HTML, CSS, JavaScript and Tailwind CSS. For mobile applications we use Flutter and Dart.

On the backend, we use Node.js and Express.js, supported by MongoDB and Firebase for data and application services.

We also work with REST APIs and Postman for API development and testing, while Git, GitHub, VS Code and Android Studio support our development workflow.

04 / How the stack works Design → Build → Connect

From design
to product.

Different technologies come together at different stages of a product's journey.

STEP 01 / DESIGN

Shape.

We use Figma and FigJam to create user flows, wireframes, interface designs, prototypes and product experiences before development.

STEP 02 / DEVELOP

Build.

React.js powers web interfaces while Flutter and Dart support mobile applications. Node.js and Express.js handle backend development.

STEP 03 / CONNECT

Connect.

MongoDB and Firebase support data and services, while REST APIs and Postman help connect, develop and test application functionality.
